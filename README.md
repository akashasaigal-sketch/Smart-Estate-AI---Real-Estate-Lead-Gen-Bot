# 🏢 NEXUS - AI Real Estate Assistant

**NEXUS** is an interactive, 24/7 AI-powered Real Estate Assistant designed for real estate agencies in Lahore, Pakistan. Powered by the Google Gemini API (`gemini-2.5-flash`) and Streamlit, it automates customer inquiry handling, lead qualification, and site-visit scheduling in localized Roman Urdu / English.

---

## ✨ Features
- **Localized Conversations:** Speaks fluently in professional Roman Urdu/English tailored for the Lahore property market.
- **Lead Qualification:** Automated flow to capture intent (Buy/Rent), property type, budget, and target location (DHA, Gulberg, Bahria Town, etc.).
- **Quick Action Buttons:** Fast interactive sidebar triggers for common inquiries (Buy, Rent, Office Location).
- **Session Reset:** Easily clear active chat history and restart sessions.
- **Dynamic Context Handling:** Uses multi-turn conversation memory via Gemini API.

---

## 🛠️ Tech Stack
- **Frontend / UI:** [Streamlit](https://streamlit.io/)
- **LLM / AI Model:** [Google Gemini API](https://ai.google.dev/) (`google-genai` SDK)
- **Language:** Python 3.10+
